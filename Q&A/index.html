• HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure the framework of web pages across the internet.

  • CSS stands for Cascading Style Sheets, and it is the standard style sheet language used to define the visual presentation, layout, and design of web pages written in HTML.

  • JavaScript (JS) is a lightweight, versatile programming language primarily known for bringing interactivity and dynamic capabilities to web pages. Alongside HTML (which provides structural meaning) and CSS (which handles styling), JavaScript serves as the third core standard technology of the World Wide Web

  • React (also known as React.js or ReactJS) is a popular, open-source JavaScript library used for building user interfaces (UIs), primarily for single-page web applications. Developed by Meta (formerly Facebook) in 2013, it allows developers to create fast, scalable, and interactive web applications by organizing code into reusable building blocks.

  • Node.js is a free, open-source, and cross-platform JavaScript runtime environment that allows developers to execute JavaScript code outside of a web browser.
